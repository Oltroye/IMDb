# Projet de Manipulation de Données en Python

Ce projet consiste à manipuler et analyser des données en utilisant le langage de programmation Python. L'objectif est de fournir des outils et des scripts pour traiter des ensembles de données, effectuer des analyses statistiques et visualiser les résultats. Ce projet analyse les critiques IMDB en utilisant des techniques de NLP et de machine learning.

## Prérequis

Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine :

- Python 3.x
- pip (gestionnaire de paquets Python)
- Les bibliothèques Python suivantes :
    - pandas
    - numpy
    - matplotlib
    - seaborn

## Installation

1. Clonez le dépôt.
2. Installez les dépendances avec `poetry install`.
